Kebijakan Privasi KelzNex

1. Data yang Kami Minta

Kami hanya meminta izin akses yang mutlak diperlukan lewat API Resmi TikTok: untuk menghubungkan akun, mengunggah konten, dan membaca info profil dasar saja.

2. Cara Penggunaan Data

  • Hanya digunakan untuk menjalankan fungsi layanan yang Anda minta
  • Tidak pernah menyimpan, menjual, atau membagikan data pribadi maupun konten Anda ke pihak lain
  • Token akses hanya disimpan di perangkat atau server yang dilindungi enkripsi

3. Keamanan

Seluruh pertukaran data berjalan lewat sambungan terenkripsi standar industri. Kami tidak menyimpan kata sandi akun TikTok Anda sama sekali.

4. Hak Anda

Anda bisa mencabut akses aplikasi kapan saja lewat pengaturan keamanan akun TikTok Anda.
